# Курсова робота: «Розробка мобільних застосунків під ОС Android»

Готові файли:

- `Kursova_Weather_Android.pdf` — зверстаний документ (42 сторінки, ~37 сторінок тексту).
- `Kursova_Weather_Android.docx` — той самий текст у Word для подальшого редагування
  (Times New Roman 14 pt, інтервал 1,5, поля 2,5/1,5/2/2 см, відступ 1,25 см).

## Структура

| Файл | Призначення |
| --- | --- |
| `content1.py` | ВСТУП, РОЗДІЛ 1 (теоретичні основи) |
| `content2.py` | РОЗДІЛ 2 (інструменти та архітектура) |
| `content3.py` | РОЗДІЛ 3 (практична реалізація застосунку «Weather») |
| `content4.py` | ВИСНОВКИ, СПИСОК ВИКОРИСТАНИХ ДЖЕРЕЛ |
| `build_pdf.py` | верстка PDF (ReportLab, шрифт Tinos як метричний аналог Times New Roman) |
| `build_docx.py` | генерація DOCX (python-docx) |
| `generate_figs.py` | побудова схем (matplotlib) у `figs/` |
| `format_content.py` | переформатування `contentN.py` після редагувань |
| `edit_blocks.py` | дрібні правки блоків за префіксом тексту |

## Як перезібрати

```bash
python3 generate_figs.py      # за потреби — перемалювати схеми
python3 build_pdf.py          # -> Kursova_Weather_Android.pdf + карта сторінок
python3 build_docx.py         # -> Kursova_Weather_Android.docx
```

Для PDF потрібні шрифти `/tmp/out_fonts/Tinos-400.ttf` і `Tinos-700.ttf`
(Tinos — вільний метричний аналог Times New Roman із кирилицею).
Якщо їх немає, їх можна зібрати з пакета `@fontsource/tinos` (`fontTools.merge`).

## Формат блоків

```python
("h1", "РОЗДІЛ 1. …")                  # нова сторінка, по центру, напівжирний
("h2", "1.1. …")                       # підрозділ, по центру, напівжирний
("p", "текст абзацу")                  # абзац із відступом 1,25 см, за шириною
("list", ["пункт", "пункт"])           # маркований список
("code", "Лістинг 3.4.1 – …", "код")   # підпис + моноширинний код
("fig", "figs/fig.png", "Рисунок …", 12.0)   # рисунок (ширина в см)
("table", "Таблиця 1.2.1 – …", [шапка], [[рядок], …])
("ref", ["Джерело 1 …", …])            # нумерований список джерел
```
